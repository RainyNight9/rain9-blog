# 3个月进阶路线（AI全栈+无人驾驶工程）

主打**快速落地、技能复用、软硬结合**，每天有效学习2.5~3小时，周末加练实操，每阶段有明确验收标准，资源+任务+项目全部配齐。

整体路径：Web AI入门 → 无人驾驶仿真+ROS2 → AI与车端系统打通，最终产出可展示完整项目。

---

## 第一月：AI全栈基础（Web端AI，复用前端技能）

**核心目标**：掌握浏览器/前端侧AI开发，跑通大模型、AI Agent，完成首个可演示项目
**技术栈**：Transformers.js、LangChain、WebGPU、React/Vue、Prompt工程

### 第1周：环境搭建 + AI基础概念
1. 任务
   - 梳理AI基础术语：大模型、量化、推理、Embedding、Agent
   - 搭建本地前端工程（React），配置`Transformers.js`运行环境
   - 学习WebGPU基础，了解前端硬件加速对AI推理的作用
2. 学习资源
   - 文档：[Transformers.js 官方文档](https://huggingface.co/docs/transformers.js)
   - 入门视频：B站「Web端AI开发入门」
3. 实操&验收
   - 本地浏览器加载轻量模型（如`Xenova/TinyLlama-1.1B-Chat-v1.0`）
   - 实现基础文本对话功能，**验收：页面正常交互、模型推理无报错**

### 第2周：前端CV模型（图像识别）
1. 任务
   - 学习前端目标检测、图像分类基础
   - 使用Transformers.js加载视觉模型，对接网页摄像头
2. 实操&验收
   - 开发网页：调用摄像头 + 实时物体检测
   - **验收**：摄像头画面可正常识别常见物体（人、车辆等）

### 第3周：LangChain + 简易AI Agent
1. 任务
   - 学习Agent核心逻辑：工具调用、任务拆解、记忆管理
   - 掌握LangChain.js基础用法，链接大模型与自定义工具
2. 实操&验收
   - 开发代码助手Agent：输入需求，自动生成前端/简单后端代码
   - **验收**：可自主拆解任务、调用工具输出可用代码片段

### 第4周：整月项目整合 + 优化
1. 任务
   - 整合前3周功能，做成单页AI应用
   - 学习模型量化（4/8bit），优化前端加载速度、推理延迟
2. 最终项目：**Web AI多功能工作台**
   - 功能：文本对话、实时图像检测、代码助手Agent
   - **验收标准**：项目可离线运行，加载速度≤5s，推理流畅；整理代码上传GitHub

## 第二月：无人驾驶入门（ROS2 + CARLA + 3D可视化）
**核心目标**：吃透ROS2基础、搭建CARLA仿真环境，结合你的3D/前端能力做车端可视化
**技术栈**：ROS2 Humble、CARLA仿真、Three.js、ROS2 Bridge

### 第5周：ROS2 核心基础
1. 任务
   - 安装ROS2 Humble（Windows/WSL2/Ubuntu 三选一，推荐WSL2适配Windows）
   - 掌握核心概念：节点、话题、服务、消息类型、参数
   - 练习基础命令行、Python/C++极简节点编写（优先Python降低门槛）
2. 资源
   - 官方教程：[ROS2 入门教程](https://docs.ros.org/en/humble/Tutorials.html)
   - 配套：B站「ROS2 零基础入门」
3. 验收
   - 实现节点间话题收发消息，**验收**：通信正常，理解数据流转逻辑

### 第6周：CARLA仿真环境搭建 + 基础车辆控制
1. 任务
   - 安装CARLA最新稳定版，熟悉仿真场景、车辆、传感器配置
   - 学习CARLA Python API，实现车辆手动控制、自动巡航
   - 对接ROS2：CARLA数据桥接到ROS2话题
2. 实操&验收
   - 仿真场景内实现**车辆车道保持、基础跟车**
   - **验收**：车辆可沿车道稳定行驶，传感器数据正常推送到ROS2

### 第7周：无人驾驶传感器数据解析
1. 任务
   - 了解主流传感器：相机、激光雷达（点云）、毫米波雷达
   - 解析ROS2图像、点云消息格式
2. 实操&验收
   - 在RViz中可视化相机画面、激光雷达点云
   - **验收**：仿真环境障碍物、道路信息可正常可视化

### 第8周：前端3D可视化对接（发挥你的核心优势）
1. 任务
   - 学习`rosbridge_suite`，实现ROS2 ↔ Web端通信
   - 结合Three.js/React，搭建Web可视化大屏
2. 整月项目：**无人驾驶仿真监控平台**
   - 功能：仿真场景3D展示、车辆姿态实时同步、相机/点云数据投屏、车速/位置数据面板
   - **验收标准**：Web端与仿真环境数据延迟<200ms，画面流畅；项目代码归档

## 第三月：AI + 无人驾驶 全链路打通（形成核心竞争力）
**核心目标**：把第一月的AI模型部署到车端仿真系统，实现**车端感知+AI识别+可视化告警**完整链路
**技术栈**：模型部署、Wasm、ROS2+AI联动、目标检测落地

### 第9周：模型轻量化 + 车端适配
1. 任务
   - 学习模型部署基础：模型转换、轻量化、端侧推理
   - 将第一月训练/使用的目标检测模型，转为适配嵌入式/仿真的格式
2. 实操&验收
   - 在本地PC（模拟车端）实现模型离线推理
   - **验收**：模型可读取图像数据，完成车辆、行人检测

### 第10周：ROS2 + AI 联动开发
1. 任务
   - 编写ROS2感知节点：读取车载相机图像 → 送入AI模型推理 → 输出识别结果
   - 设计告警逻辑：检测到近距离障碍物，触发预警消息
2. 实操&验收
   - 仿真车辆行驶时，AI实时识别行人、非机动车
   - **验收**：识别结果准确，可正常发布预警话题

### 第11周：全链路功能迭代 + 交互优化
1. 任务
   - 打通全链路：CARLA仿真 → ROS2采集数据 → AI感知识别 → Web大屏展示+告警
   - 优化逻辑：过滤误识别、优化推理速度、完善告警弹窗/指示灯效果
2. 拓展功能：增加车道线识别，辅助车辆行驶决策

### 第12周：最终项目收尾 + 复盘 + 简历素材整理
1. 任务
   - 整合所有模块，完成**端到端无人驾驶AI仿真系统**（结业项目）
   - 撰写项目文档：架构图、技术选型、功能介绍、踩坑总结
   - 录制演示视频，整理GitHub仓库（README完善）
2. 最终验收（硬性标准）
   1. 仿真车辆正常行驶，AI可精准识别道路参与者、车道线
   2. 障碍物近距离触发Web端声光告警
   3. 全系统稳定运行10分钟以上，无崩溃、无明显卡顿
3. 附加动作
   - 提炼项目亮点，直接写入简历/作品集，作为转行核心案例

## 配套补充：通用规则 & 避坑指南
### 一、学习节奏安排（适配在职）
- 工作日：每晚 20:00-22:30（2.5h），主攻**理论+代码编写**
- 周末：半天（4h）集中调试项目、排错、补薄弱知识点
- 原则：**先跑通功能，再深究原理**，在职学习优先保证落地

### 二、环境推荐（按易用度排序）
1. 主力系统：Windows + WSL2（运行ROS2/CARLA，兼顾日常前端开发）
2. 代码工具：VS Code（统一前端、Python、C++开发）
3. 版本控制：全程使用Git/GitHub管理所有项目代码

### 三、重点避坑
1. 不要一上来死磕C++底层：前两个月优先用Python快速落地，第三个月再逐步改写核心模块
2. 不要沉迷看视频不动手：**每学1小时理论，必须配1小时实操**
3. 仿真环境报错优先查官方issue、社区问答，减少无效内耗

### 四、后续延伸方向（3个月完成后）
1. 短期（3~6月）：深耕**车端可视化、数据标注平台、仿真工具链**（最贴合你现有能力）
2. 中期（6~12月）：学习C++进阶、嵌入式基础，切入真实车载工程开发
3. 长期：结合MEM工程管理知识，往**技术负责人、系统架构师**方向发展
